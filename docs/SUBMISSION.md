## Checklist

- [ ] Public GitHub repo: clean history, single `main` branch, no `node_modules`, no `.env*`
- [ ] Live Vercel URL works in an incognito window and on a phone
- [ ] README has the live URL, video link, problem, features, stack and prompts
- [ ] "Try a sample" works even with the API key removed (fallback)
- [ ] Lighthouse screenshot (≥ 90) added to the README
- [ ] `npm test` passes
- [ ] Demo video uploaded (YouTube unlisted or Drive with public view) and linked
- [ ] Form submitted on Hack2skill before **Oct 31** (one day of buffer)
